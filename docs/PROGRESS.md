## M0 脚手架与设计基线（2026-11-20）

### 交付内容

- **脚手架**：`create-payload-app@3.94.0`（blank 模板 + PostgreSQL）→ Next.js 16.4.6、Payload 3.94.0、React 19.2；后台简体中文。
- **工具链**
  - ESLint flat config（`eslint-config-next` 原生配置，`--max-warnings=0`，禁止 any / ts-ignore，强制 type import）。
  - Prettier；`pnpm check` = 类型检查 + lint + 格式检查 + 测试。
  - Vitest 两个 project：`unit`（无数据库）、`int`（自动切换到 `*_test` 测试库）。
  - Playwright：desktop 1440 / mobile 390，针对生产构建运行；fixture 自动断言 **控制台无报错** 且 **无第三方域名请求**。
- **设计令牌** `src/styles/globals.css`：原始令牌（`@theme static`）+ 语义令牌（light / paper / dark 三种区块，可嵌套）。
- **基础组件**：Button、Input、Textarea、Label、Checkbox、Badge、Separator、Skeleton（shadcn 改造）；Container、Section、SectionHeading、SkipLink、StatusPage。
- **设计规范页** `/styleguide`：色板、三种区块下的实时对比度表、字号、间距、圆角、阴影、组件在三种区块上的效果、学员作品区块示意。
- **页面**：路由内 404（`not-found.tsx`）、未匹配路由 404（`global-not-found.tsx`）、错误页（`retry()` 重新获取）、临时首页（noindex，M5 替换）。
- **本地开发**：`docker-compose.dev.yml`（PostgreSQL 16，自动创建 `eduverse_test`）。
- **文档**：`docs/PRD.md`、`docs/ARCHITECTURE.md`、`CLAUDE.md`、`README.md`、本文件。

### 关键决策

1. **品牌色 CTA 用近黑文字**：白字在 `#FF5B14` 上仅 3.11:1，不达 AA；近黑字 6.29:1，且保住高饱和度。
2. **令牌两层结构**：原始令牌 + 语义令牌；组件只用语义类，`<Section tone>` 切换深浅区块时自动适配。对比度由单元测试按 WCAG AA 校验（20 组 × 3 区块），`/styleguide` 实时展示同一份清单。
3. **中文不下载字体**：系统字体栈；只自托管 22KB 的 Space Grotesk 拉丁子集用于标题西文和数字。
4. **tailwind-merge 注册自定义令牌**：否则 `text-h2` 会被当成颜色与 `text-foreground` 冲突而被丢弃（已加回归测试并与 CSS 同步校验）。
5. **未匹配路由 404 使用 `global-not-found`**：前台与后台是两个根布局，这是 Next 官方给出的方案（实验特性，升级时回归）。
6. **e2e 针对生产构建**：更接近线上；集成测试使用独立测试库。
7. **关闭境外遥测与外链**：Next 遥测（环境变量）、Payload 遥测（配置）、Gravatar（配置），并由 e2e 统一兜底。
8. **ESLint 改为原生 flat config**：模板自带配置依赖未安装的 `@eslint/eslintrc`，无法运行。

### 关键决策

1. **Payload 内置 `slugField` + 拼音**：后台自带“自动生成 / 锁定”交互，中文标题转无声调拼音，统一校验格式。
2. **哪些内容有草稿**：有详情页或需要发布控制的内容启用草稿；开班计划、软件、合作企业、FAQ 等参考数据不启用。前台数据层必须显式过滤 `_status: published`（已写入 CLAUDE.md）。
3. **线索防伪造**：状态历史始终从数据库原值重建，提交的历史被忽略；已有跟进记录保留原作者与时间。
4. **缓存失效在 Next 运行时之外自动跳过**（种子脚本、集成测试），避免误报。
5. **种子数据骨架 + 类型化引用**：`registry.ts` 定义 slug，内容文件引用类型化 slug，写错即编译失败；`seed-data.test.ts` 校验数量、引用与广告法禁用词。
6. **占位图本地生成**：sharp 渲染 SVG，同一种子结果一致；中文依赖系统字体（CI 安装文泉驿正黑）。
7. **测试隔离**：集成测试使用独立的 `eduverse_test` 库与系统临时目录中的媒体目录（发现并修复了种子测试会覆盖开发环境 `media/` 的问题）。
8. **页脚二维码图片为必填**：重置时先清空页脚二维码再删除媒体，否则外键置空失败导致整个删除事务回滚（已修复并由“重复执行”集成测试覆盖）。
9. **迁移策略**：开发与预览站用 Payload 的自动建表（push）；生产部署使用迁移文件（M8 配置启动时自动执行迁移）。

### 已知问题 / 限制

- 前台页面尚未接入数据（M2 起逐步实现），预览站首页仍为临时页。
- 免费教程的 BV 号是格式合法的占位值，不对应真实视频；正式使用时在后台替换。
- 隐私政策、用户协议是草稿，页面内已注明“正式上线前须经法务审核”。
- Payload 后台在 390px 下列表表格横向滚动、关联字段异步加载，属于 Payload 自身界面行为。
- 当前云端环境的 PostgreSQL 会随会话进程重启而停止，需要时手动启动（不影响项目本身）。
