# 参考站版式与交互分析：m.itheima.com（移动端）

> 2026-11-23 应产品方要求，以手机浏览器（iPhone 配置）方式查看；该站只对手机浏览器提供页面，桌面浏览器会返回“访问被阻断”。
> 依据 PRD §0 Q6：**只借鉴版式与交互**，不复制其品牌、配色、Logo、文案、图片与数据。本文只做结构性描述，不保存对方素材。
> 对方页面中存在“毕业即就业”“就业率 xx%”“年薪 30w+”等效果承诺与未注明出处的统计，属于本项目明确不做的内容（PRD §7、广告法第 24 / 11 条）。

## 2. 首页区块顺序（移动端）

1. **主视觉**：带左右留白的圆角横幅卡片（不贴边）。→ 我们采用同样的“内缩横幅”，圆角用设计令牌（6–10px），可轮播。（M5）
2. **四宫格快捷入口**：紧跟主视觉，图标 + 两字标签，均为高意向入口（开班时间、学费、校区、就业）。→ 对应首页“快速了解”区块；入口改为“近期开班 / 咨询学费 / 校区分布 / 职业测试”等，图标用线性功能图标，不用彩色插画。（M5）
3. **方向宫格**：3 列小卡片（名称 + 一句话卖点），末尾“了解更多 >”。→ 热门专业在移动端用 2–3 列宫格，桌面端用 Tab。（M5）
4. **课程横滑卡片**：顶部可横向滚动的 Tab，下方大卡片可左右滑动；卡片内含方向名、一句话定位、简介、**编号式学习路线**、两个按钮（课程详情 / 申请试听）。→ 课程卡片加入“学习路线概览”（取课程阶段名）与双按钮，移动端横向滑动（scroll-snap）。（M3 / M5）
5. **试听促销条**：窄横条 + 右侧按钮。→ 改为“免费预约试听”横条（不展示价格，学费走咨询）。（M5）
6. **就业成果列表 + 学员好评横滑**：→ 不做就业率 / 薪资数字；用学员故事（化名、无个人薪资）横滑卡片代替。（M5 / M6）
7. **资料领取列表**：每行一个方向的学习资料，点击留资领取。→ 对应“领取资料”意向：按专业方向列出资料包，点击打开留资弹窗（intent=materials）。（M2 组件，M5 / M7 使用）
8. **合作企业横滑卡片**：→ 我们用合作企业 Logo 墙（虚构企业），可横滑。（M5 / M6）
9. **讲师列表**：卡片内 3 位讲师一页（姓名 + 头衔 + 两行简介），可翻页。→ 讲师区块移动端用同样的分页列表，桌面端用网格。（M4 / M5）
10. **就业服务清单**：图标 + 标题 + 一句说明的纵向列表。→ 就业服务流程区块。（M6）
11. **校区横滑卡片**：背景图 + 校区名、地址、电话 + 两个按钮（看校区 / 开班详情）。→ 校区卡片：地址、电话、“查看校区”“在地图中打开”。（M5 / M6）
12. **资讯 Tab 列表**：三个分类 Tab，下面是标题列表。→ 首页资讯区块按文章分类 Tab 切换，列表式。（M5）
13. **页脚转化区**。（M2）

## 3. 可借鉴的交互要点

- **横滑优先**：课程、学员评价、合作企业、讲师、校区都用“可横向滑动 + 底部进度条”的卡片组，减少首页纵向长度。→ 统一封装为一个横滑容器组件（CSS scroll-snap + 进度指示，键盘可操作），不引入轮播库。
- **每张课程卡都有两个出口**：看详情 / 直接试听，转化路径短。→ 课程卡与课程详情吸顶栏都提供“预约试听”。
- **区块标题居中、关键词强调**：→ 移动端区块标题可居中，关键词用 `text-emphasis`（橙 700），不使用品牌橙底色。
- **菜单即导购**：菜单本身就是课程目录 + 校区目录。→ 移动端抽屉菜单照此设计。

## 4. 不采用的部分

- 品牌红 / 多彩渐变按钮、彩色插画图标（与本项目“石墨 + 电光橙只用于 CTA”的视觉方向冲突）。
- 大圆角卡片堆叠的整体观感（M0 设计令牌已限定圆角）。
- 价格促销、名额紧迫感（“限时抢报”“优先占座”）、效果承诺与无出处统计。
