## 1. 背景与目标

- 参考对象：hxsd.com（火星时代教育，数字艺术职业培训机构官网）。为「EduVerse 数艺学院」（一家数字艺术 / 设计职业培训机构）建设同类型网站。
- **只借鉴信息架构、功能和转化路径**。品牌名、Logo、配色、文案、图片、课程内容、学员作品全部原创或用占位，不得复制或抓取对方任何素材。
- 参考站有反爬验证，**不访问、不尝试绕过**；需要参考时由产品方提供截图。
- 网站目标：
  1. 访客能快速找到适合自己的专业和课程；
  2. 用学员作品、就业成果、师资建立信任；
  3. 把访客转化为留资线索（预约试听 / 咨询学费 / 领取资料），交给课程顾问跟进；
  4. 通过资讯内容做搜索引擎获客（以百度为主）。
- 目标用户：想入行或转行的零基础成年人、大学生、想进阶的在职设计师。

## 2. 技术栈

- Next.js（App Router，16.x 稳定版）+ TypeScript strict + Tailwind CSS v4 + shadcn/ui，包管理 pnpm
- Payload CMS 3 集成在同一个 Next.js 项目（自带后台、权限、媒体库、富文本），PostgreSQL；用官方脚手架 `create-payload-app` 初始化，保证版本兼容
- zod 校验；Vitest 单元测试；Playwright 端到端测试
- 部署：Docker + docker-compose（app + postgres），目标国内云服务器；媒体文件先存本地磁盘，保留切换到 S3 兼容对象存储（阿里云 OSS / 腾讯云 COS）的能力
- 面向中国大陆用户：**不得依赖** Google Fonts、Google Analytics、reCAPTCHA 等大陆无法稳定访问的服务；字体用系统中文字体栈或自托管

技术细节、目录结构、数据模型见 `docs/ARCHITECTURE.md`。

## 3. 站点结构（MVP）

### 3.1 全局
- **顶部导航**：首页 / 专业课程（悬停展开大菜单，按专业方向列出课程）/ 学员作品 / 就业服务 / 师资 / 校区 / 资讯 / 关于我们；右侧是搜索和“预约试听”按钮。
- **右侧悬浮栏**：在线咨询（只预留第三方客服代码位，不自建聊天系统）、电话、微信二维码、预约试听、返回顶部；**移动端改为底部固定操作条**。
- **页脚**：专业导航、联系方式、二维码、隐私政策 / 用户协议、ICP 备案号和公安备案号（后台可配置）。

### 3.2 页面
1. **首页**：主视觉轮播 → 快捷入口（职业测试 / 免费教程 / 学员作品 / 预约试听）→ 热门专业 Tab（简介、发展方向、薪资参考、近期开班、CTA）→ 精选作品 → 就业成果与学员故事 → 师资 → 校区分布 → 合作企业 → 最新资讯 → 底部留资表单。
2. **课程列表 `/courses`**：按专业方向、班型（长期就业班 / 短期提升班）、授课方式（线下 / 线上 / 双师）、城市筛选；筛选条件同步到 URL，可直接分享。
3. **课程详情 `/courses/[slug]`**：核心信息（时长、班型、授课方式、开设校区、近期开班）、适合人群、分阶段课程大纲（可折叠）、所用软件、实训项目、本课程学员作品、讲师、就业方向与薪资参考、FAQ；CTA 吸顶。
4. **专业方向 `/majors/[slug]`**（新增）：专业介绍、发展方向、薪资参考、该方向课程、作品、讲师、CTA。
5. **学员作品 `/works`**：瀑布流，按专业、软件、是否精选筛选，懒加载；**详情 `/works/[id]`**：大图或视频、作者、所属课程、所用软件、相关作品，支持灯箱浏览。
6. **就业服务 `/careers`**：服务流程（作品集打磨、简历、模拟面试、企业内推）、学员故事、合作企业、招聘活动。
7. **师资 `/teachers`** 及详情 `/teachers/[slug]`；**校区 `/campuses`** 及详情 `/campuses/[slug]`（地址、交通、环境照片、开设课程、联系方式；地图先用“在高德 / 百度地图中打开”链接）。
8. **资讯 `/articles`**：分类（学院新闻 / 行业资讯 / 学习干货 / 常见问题）；详情页含面包屑、作者、发布时间、阅读量、相关文章，侧栏放热门课程和留资卡片。
9. **免费教程 `/tutorials`**：视频列表（嵌入 B 站等外部播放器），部分教程留资后解锁。
10. **职业测试 `/quiz`**：8–10 道选择题 → 推荐专业方向 → 留资后获取完整报告。
11. 关于我们、联系我们、隐私政策、用户协议、站内搜索（MVP 用数据库模糊匹配，中文分词以后再做）、404。

## 4. 留资系统（核心转化）

- 同一个留资组件，支持**弹窗、页内、侧栏**三种形态；字段：姓名、手机号、意向专业、所在城市、留言（选填）。
- 手机号按大陆号段校验（`^1[3-9]\d{9}$`，不维护精确号段表，避免误拒新号段）。
- 必须勾选“已阅读并同意《隐私政策》”才能提交（个人信息保护法要求告知并取得同意）；记录同意时间与隐私政策版本号。
- 自动记录来源：提交页 URL、按钮位置标识（如 `home_hero`、`course_sticky`）、UTM 参数、referrer、首次落地页。
- 防刷：honeypot + 最短填写时间 + 按 IP 和手机号限频，服务端再校验一遍；IP 阈值宽松（避免 NAT 误伤），手机号阈值严格，阈值后台可配。
- 提交后给出明确反馈并引导添加微信；后台可配置 webhook，把新线索推送到企业微信 / 飞书 / 钉钉群机器人（支持加签；推送内容默认手机号脱敏；仅允许三家官方域名，防 SSRF）；推送走任务队列，失败重试。
- 后台线索管理：列表、筛选、状态流转（新线索 → 已联系 → 已到访 → 已报名 / 无效）、分配顾问、跟进备注、导出 CSV（UTF-8 BOM、防公式注入、导出留痕）；**顾问只能看自己的线索**；内容编辑无权访问线索。
- 线索增加“意向类型”：预约试听 / 咨询学费 / 领取资料 / 职业测试 / 教程解锁 / 在线咨询，由触发按钮决定。

## 5. 后台（CMS）

- 内容类型：专业方向、课程、开班计划、软件、讲师、学员作品、文章（及分类）、校区、轮播图、合作企业、学员故事、招聘活动、FAQ、免费教程、测试题、通用页面；全局配置：站点设置（电话、二维码、备案号、统计代码、默认 SEO）、导航、页脚、首页、就业服务页、测试设置、留资设置。
- 角色：**管理员、内容编辑、课程顾问**。
- 前台所有营销文案、图片、导航都来自 CMS 或配置，不硬编码在组件里。系统级提示语（表单校验错误、分页、空状态等）集中在 `src/i18n/zh.ts` 字典中，不散落在组件里。

## 6. 设计

- 气质：专业、年轻、有设计感，**作品是主角**。多用大图和深色区块衬托作品，一个高饱和强调色（电光橙 `#FF5B14`）专门用于 CTA。
- 先定义设计令牌（颜色、字号、间距、圆角、阴影），再写页面；中文正文 16px、行高约 1.7，标题层级清晰。
- 避免“AI 模板感”：满屏紫色渐变、千篇一律的大圆角卡片、无意义的装饰图标。
- 响应式：1440 / 768 / 390 三档都要认真适配，移动端优先保证留资路径顺畅。
- 无障碍：语义化 HTML、图片 alt、键盘可操作、对比度达到 WCAG AA；轮播可暂停并尊重 `prefers-reduced-motion`。

## 7. SEO、性能与合规

- 服务端渲染；每页可在后台配置 TDK（title / description / keywords）；canonical、Open Graph；自动生成 `sitemap.xml` 和 `robots.txt`；结构化数据（Organization、Course、Article、BreadcrumbList）。
- 课程和文章使用语义化 slug URL（文章 slug 由标题自动生成拼音，可手改）。
- 百度专项：`applicable-device`、`Cache-Control: no-transform`、站长验证 meta；筛选组合页 `noindex,follow` + canonical，防爬虫陷阱。
- 移动端 Lighthouse Performance ≥ 85（首页、课程详情、文章详情；Lighthouse 默认移动端模拟口径）；图片用 `next/image` 并设置正确的 `sizes`；第三方客服 / 统计脚本延迟加载。
- **广告法**：
  - 文案不用“最好、第一、顶级”等绝对化用语；
  - 不做“包就业、保证高薪”之类的效果承诺；
  - 薪资数据必须标注来源和统计时间，并注明“不作为培训效果承诺”；
  - 不展示无法核实的“就业率”类统计；
  - 学员故事按 §0 Q4 口径处理（第 24 条：不得利用受益者名义或形象作推荐、证明）。
- **个人信息保护**：隐私政策需写明收集目的、第三方（企业微信 / 飞书 / 钉钉、客服、统计服务商）、保存期限与删除方式；文本由我方起草并标注“需法务审核”。
- ICP 备案号、公安备案号后台可配置；未备案域名在国内服务器无法开放 80/443 端口。

## 8. 种子数据

- 生成可信但虚构的中文数据：8 个专业方向、24 门课程、60 件作品、12 位讲师、6 个校区、30 篇文章、20 家合作企业（虚构名称）、10 道测试题；企业、机构、人名全部虚构；软件只写名称，不用厂商 Logo。
- 用脚本在本地生成占位图（不同色调渐变 + 类别文字），不外链第三方图片，更不得抓取 hxsd.com。
- 提供一条命令一键重置种子数据（`pnpm seed:reset`）。

## 10. 完成标准（每个里程碑都适用）

- 类型检查、lint、测试、生产构建全部通过，浏览器控制台无报错。
- 已交付功能不留 TODO 占位；空状态、加载态、错误态都要处理。
- 用 1440px 和 390px 宽度截图自查。
- 从 M2 起，端到端测试覆盖留资关键路径；从 M5 起覆盖完整路径：首页 → 课程详情 → 提交预约试听 → 后台能看到这条线索，来源字段正确。
- 不随意引入新依赖；确需引入时说明理由（记录在 `docs/PROGRESS.md`）。
- 每个里程碑结束：git 提交，汇报（做了什么、怎么查看、已知问题、下一步），停下等待确认。
